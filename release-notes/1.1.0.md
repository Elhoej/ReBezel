## What's new

- Hold Control while pressing a brightness key to change the brightness of an external display. This works with displays macOS itself can control (Studio Display, Pro Display XDR, LG UltraFine), not third-party monitors over DDC. ReBezel picks the display under the pointer, or the first supported one, and shows the bezel on it. With no supported display connected, the key goes to macOS as usual.
- ReBezel can now update itself. Choose Check for Updates… from the menu bar icon, or leave "Automatically check for updates" on in Preferences and it checks once a day. It always asks before installing anything.
- A new app icon, built for the Liquid Glass look of macOS 26, with a dark mode variant.
- The app is signed with a Developer ID and notarized by Apple, so macOS opens it without a Gatekeeper warning.

## Before you update

Install this version by hand from the DMG. Updates after it arrive through the app.

macOS ties Accessibility permission to the app's signature, so if you ran an earlier build you need to grant it once more in System Settings → Privacy & Security → Accessibility. Later updates keep it.
